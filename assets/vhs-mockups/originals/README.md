# Lokale Photoshop-kilder

Vanlig oppstart bruker Sharp og ferdige runtime-lag i `public/VHS/templates`. Photoshop-rendereren er et valgfritt lokalt designverktøy og krever egne lisensierte PSD-kilder. Kjøpte PSD-originaler følger ikke med den gjenbrukbare malen og skal ikke legges i Git.

Eldre Git-historikk kan inneholde designkilder; denne oppryddingen endrer kun dagens filtres oppsett og omskriver ikke historikken. Runtime-lag og filmmedier har egne rettigheter; se [medier og gjenbruk](../../../docs/media-and-reuse.md).
